# Security policy

## Supported versions

AzanBoki is currently an early release. Security fixes are applied to the
latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security** tab to open a private vulnerability report. Include a
clear description, affected platform, reproduction steps, and potential impact.

You should receive an acknowledgement within seven days. Please allow time to
investigate and prepare a fix before public disclosure.
